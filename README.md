# Casa do Shake — site estático (GitHub Pages)

Página única recriada à mão a partir do WordPress/Elementor (sem PHP, sem JS):
logo + 3 botões (Instagram, Loja Virtual, WhatsApp).

- Visual fiel ao original: fundo `#236633`, botões Montserrat 600 com borda
  `#7cba46` (verde-claro nos botões Instagram/WhatsApp, escuro no Loja Virtual).
- `assets/`: logo + favicons copiados da produção e `og:image` absoluto.

## Testar localmente

```powershell
npx --yes serve .
```
