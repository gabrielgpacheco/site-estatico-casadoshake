# Casa do Shake — site estático

Página única em HTML+CSS puro (sem PHP e sem JS): logo e botões de Instagram,
Loja Virtual, WhatsApp e Reset 5 Dias.

- Visual fiel ao original: fundo `#236633`, botões Montserrat 600 com borda `#7cba46`.
- `assets/`: logo, favicons e `og:image`.

## Testar localmente

```powershell
npx --yes serve .
```

## Deploy

Hospedado no GitHub Pages (branch `main`, raiz); o domínio é definido pelo arquivo `CNAME`.
